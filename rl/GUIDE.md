# Папка `rl`: как устроена и как запустить агента

Практическая инструкция: что где лежит, как запустить обученного агента на нужном уровне (в том
числе на своём, нарисованном вручную), как следить за обучением из консоли.
Почему агент устроен именно так — в [ARCHITECTURE.md](ARCHITECTURE.md) и [MODEL.md](MODEL.md).

Все команды — в PowerShell из папки `rl`:

```powershell
cd D:\git_repo\rl
```

Python с PyTorch лежит в `..\.venv`, поэтому скрипты запускаются как `..\.venv\Scripts\python.exe скрипт.py`.
`status.py` и `make_level.py` работают и с обычным `python`.

---

## 1. Что лежит в папке

```

├── README.md             кратко: порядок работы, как следить за обучением
├── ARCHITECTURE.md       архитектура обучения (BC → PPO → игра)
├── MODEL.md              архитектура модели CNN + LSTM
├── supaplex_rl.ipynb     ноутбук: всё по шагам, с графиками
│
├── features.py           как агент «видит» игру: классы тайлов, скаляры, метки действий
├── model.py              модель CNN + LSTM (actor-critic)
├── supaplex_env.py       среда: настоящий движок игры (bin/supaplex_env.dll) + награда
├── data.py               датасет для обучения: эпизоды → окна → батчи
│
├── train_bc.py           этап 1 — обучение на решениях людей (behavior cloning)
├── train_ppo.py          этап 2 — PPO: агент играет сам и улучшается
├── evaluate.py           проверка агента на многих уровнях: % пройденных
├── play.py               ▶ агент играет на выбранном уровне (окно, 35 кадров/с), запись .SP
├── status.py             ▶ прогресс обучения в консоли
├── make_level.py         ▶ свой уровень из текстового файла
├── check_env.py          проверка: среда повторяет датасет покадрово
├── make_notebook.py      пересоздаёт ноутбук
│
├── bin/                  supaplex_env.dll (движок игры) + SDL2.dll, SDL2_mixer.dll
├── levels/               самописные уровни: example.txt → example.sp (+ example.png)
├── checkpoints/          веса и журналы обучения (создаётся при обучении)
│   ├── bc_best.pt          лучшая модель этапа 1 (по валидации)
│   ├── bc_last.pt          последняя модель этапа 1 (для продолжения)
│   ├── ppo_best.pt         лучшая модель этапа 2 (по % пройденных незнакомых уровней)
│   ├── ppo_last.pt         последняя модель этапа 2
│   ├── bc_train.log        журнал этапа 1 (текст)
│   ├── ppo_train.log       журнал этапа 2 (текст)
```

Данные для обучения — `..\datasets\solved-ns` (6895 решений). Модель обучается без кадров экрана:
ей хватает сетки уровня.

## 2. Какую модель запускать

| Чекпоинт | Когда использовать |
|---|---|
| `ppo_best.pt` | основной: агент после PPO, лучший на незнакомых уровнях |
| `ppo_last.pt` | самый свежий во время PPO-обучения |
| `bc_best.pt` | агент, который только повторяет за людьми (до PPO) |
| `bc_last.pt` | самый свежий во время BC-обучения |

`play.py` без `--checkpoint` берёт `ppo_best.pt`, а если его ещё нет — `bc_best.pt`.
Любой другой: `--checkpoint checkpoints\bc_last.pt`.

## 3. Запустить агента на уровне

### Уровень из оригинального набора (111 уровней `supaplex.dat`)

```powershell
..\.venv\Scripts\python.exe play.py --level 5                    # весь уровень на экране
..\.venv\Scripts\python.exe play.py --level 5 --view camera      # как в игре: камера за Мёрфи
..\.venv\Scripts\python.exe play.py --level 5 --deterministic    # всегда самое вероятное действие
```

Номера уровней — как в игре и в `supaplex_viewer.py` (1…111). Посмотреть все уровни:
`python ..\supaplex_viewer.py ..\supaplex.dat`.

### Уровень из другого набора (`LEVELS.D01`, `LEVELS.D02`, …)

```powershell
..\.venv\Scripts\python.exe play.py --levels-file ..\OpenSupaplex\LEVELS.D01 --level 3
```

### Уровень из файла `.SP` (демо, решение, уровень из Superplexed)

```powershell
..\.venv\Scripts\python.exe play.py --sp ..\demos\my\00S001-0.SP
..\.venv\Scripts\python.exe play.py --sp ..\demos\solves\05\05s057-1.sp
```

Из `.SP` берётся только уровень (первые 1536 байт); записанные в демо нажатия не используются.

### Окно и клавиши

Агент принимает решение каждые 4 кадра, игра идёт с настоящей скоростью — 35 кадров в секунду.

| Клавиша | Действие |
|---|---|
| `Пробел` | пауза |
| `R` | начать уровень заново |
| `N` / `P` | следующий / предыдущий уровень набора |
| `+` / `-` | быстрее / медленнее (×0.25 … ×16) |
| `D` | переключить: самое вероятное действие / случайное по вероятностям |
| `Esc` | выход |

Строка состояния: уровень, кадр, собранные инфотроны, награда эпизода, текущее действие, оценка
ценности. Ниже — какая модель играет и итоги всех сыгранных эпизодов.

### Без окна (быстро, только итог)

```powershell
..\.venv\Scripts\python.exe play.py --sp levels\example.sp --headless
# FIRST STEPS: ПРОЙДЕН!, кадров 6229, инфотронов 5/5, награда 19.99, 10.1 c
```

### Посмотреть игру агента в настоящей игре

```powershell
..\.venv\Scripts\python.exe play.py --level 5 --record agent_005.SP
..\OpenSupaplex\OpenSupaplex.exe -p agent_005.SP
```

`--record` сохраняет нажатия агента как демо игры (сохраняется, если уровень пройден; с `--headless` —
всегда). OpenSupaplex проигрывает его в оригинальной графике и со звуком. Это та же игра, что видел
агент: движок один и тот же.

### Все опции `play.py`

| Опция | Описание |
|---|---|
| `--level N` | номер уровня в наборе (по умолчанию 1) |
| `--levels-file ФАЙЛ` | набор уровней (по умолчанию `..\supaplex.dat`) |
| `--sp ФАЙЛ` | один уровень из `.SP`/`.sp` |
| `--checkpoint ФАЙЛ` | какая модель играет |
| `--view full\|camera` | весь уровень или камера за Мёрфи |
| `--scale N` | увеличение окна (по умолчанию 1 для full, 3 для camera) |
| `--deterministic` | всегда самое вероятное действие |
| `--record ФАЙЛ.SP` | сохранить игру агента как демо |
| `--headless` | без окна, только итог |
| `--max-steps N` | лимит шагов агента (по умолчанию 6000 ≈ 11 минут игры) |
| `--watch` | наблюдение за обучением (см. раздел 6) |
| `--cpu` | считать модель на процессоре |

## 4. Свой уровень

### Вариант 1: текстовый файл (быстро)

Нарисуйте карту символами, например `levels\my_level.txt`:

```text
# name: MY LEVEL
# gravity: off
# freeze_zonks: off
# infotrons: 0
WWWWWWWWWWWWWWWWWWWW
WM....B.....Z.....EW
W.WWWWBWWWWWBWWWW.WW
W..I..B..L..B..I...W
WWWWWWWWWWWWWWWWWWWW
```

```powershell
python make_level.py levels\my_level.txt                     # -> levels\my_level.sp и my_level.png
..\.venv\Scripts\python.exe play.py --sp levels\my_level.sp  # агент играет
```

| Символ | Объект | Символ | Объект |
|---|---|---|---|
| `.` или пробел | пустота | `W` | стена |
| `B` | база (зелёная плата, Мёрфи её съедает) | `C` | RAM-чип |
| `Z` | зонк (падает, катится) | `I` | инфотрон |
| `M` | Мёрфи — ровно один | `E` | выход |
| `O` | оранжевый диск | `Y` | жёлтый диск |
| `R` | красный диск | `T` | терминал |
| `S` | снік-снак (ножницы) | `L` | электрон (взрывается инфотронами) |
| `G` | баг (искрящая плата) | `>` `v` `<` `^` | порт в одну сторону |
| `\|` | порт вверх-вниз | `-` | порт влево-вправо |
| `+` | порт в 4 стороны | | |

Правила:
- поле игры — 60×24 клетки; карта может быть меньше, всё остальное заполнится стеной;
- внешняя рамка поля всегда стена;
- `# infotrons: 0` — собрать все инфотроны на карте. Можно указать число больше, тогда недостающие
  придётся получить взрывом электронов;
- `make_level.py` проверяет: один Мёрфи, есть выход, нет неизвестных символов. Он рисует
  картинку уровня (`.png`), чтобы проверить его на глаз.

Готовый пример: `levels\example.txt` → `levels\example.sp`.

### Вариант 2: редактор Superplexed (всё, включая спец-порты)

1. Запустите `..\superplexed-0_21_win-x64\superplexed.exe` и нарисуйте или измените уровень.
2. Кнопка **Save SP** сохраняет текущий уровень в `.SP` (с Shift — все уровни набора).
3. `..\.venv\Scripts\python.exe play.py --sp путь\к\уровню.SP`.

Чтобы играть свой уровень и самому в OpenSupaplex, сохраните его в набор `LEVELS.DAT`/`LEVELS.Dxx`
кнопкой Save DAT в Superplexed.

### Проверить свой уровень

- **Отдельно:** `..\.venv\Scripts\python.exe play.py --sp levels\my_level.sp --headless`. Вывод:
  пройден / погиб / лимит времени.
- **Несколько раз:** агент выбирает действия случайно по вероятностям, поэтому результат от запуска к
  запуску разный. Для стабильной оценки запустите несколько раз или используйте `--deterministic`.

## 5. Проверить агента на многих уровнях

```powershell
..\.venv\Scripts\python.exe evaluate.py --checkpoint checkpoints\ppo_best.pt --levels val --count 64
```

`--levels val` — уровни, которых модель не видела при обучении. `train` — знакомые. `original` —
уровни папки `00` (оригинальный набор). Вывод: доля пройденных, погибших, собранных инфотронов и
лучшие уровни.

## 6. Как идёт обучение: прогресс из консоли

### Одна команда — сводка

```powershell
python status.py            # один раз
python status.py --watch    # обновлять каждые 30 секунд (Ctrl+C — выход)
```

Пример:

```
=== Обучение агента Supaplex — 22.11 21:48:03 ===
ЭТАП 1 — Behavior Cloning  (журнал обновлён только что)
  шаг 23600 / 30000  [########################------]  78.7%  осталось ~28 мин
  последний шаг:  policy 0.6452  value 0.0469  acc 0.856  acc(движение) 0.849 ...
  валидация (незнакомые уровни): policy 0.4701  value 0.3691  acc 0.853  acc(движение) 0.848
  игра в среде [val]: пройдено 0.0%  инфотронов 13.5%  погиб 81.2%

ЭТАП 2 — PPO: ещё не запущен (стартует автоматически после BC)

Чекпоинты: bc_best.pt (21:45), bc_last.pt (21:45)
```

| Метрика | Что значит |
|---|---|
| `acc` | как часто модель выбирает то же действие, что человек |
| `acc(движение)` | то же, но только на шагах, где человек что-то нажимал |
| `пройдено` | доля уровней, которые агент прошёл сам |
| `инфотронов` | какую долю нужных инфотронов агент собрал |
| `погиб` | доля попыток, закончившихся гибелью Мёрфи |
| `награда` (PPO) | средняя награда эпизода: +1 инфотрон, +20 прохождение, −10 гибель |

Если в журнале ошибка, `status.py` об этом пишет.

### Журнал в реальном времени

```powershell
Get-Content checkpoints\bc_train.log -Wait -Tail 20
Get-Content checkpoints\ppo_train.log -Wait -Tail 20
```

### Графики

```powershell
..\.venv\Scripts\tensorboard --logdir runs        # открыть http://localhost:6006
```

### Смотреть, как агент учится

```powershell
..\.venv\Scripts\python.exe play.py --watch --cpu
```

Агент играет уровень за уровнем. Перед каждым эпизодом подгружается свежий чекпоинт: `ppo_last.pt`,
а пока его нет — `bc_last.pt`.

## 7. Запустить / продолжить обучение

```powershell
..\.venv\Scripts\python.exe train_bc.py --steps 30000 --workers 8              # этап 1 с нуля
..\.venv\Scripts\python.exe train_bc.py --resume --steps 30000 --workers 8     # продолжить с bc_last.pt
..\.venv\Scripts\python.exe train_ppo.py --init checkpoints\bc_best.pt --updates 2000   # этап 2
..\.venv\Scripts\python.exe train_ppo.py --resume --updates 4000               # продолжить PPO / дообучить дольше
```

Прерывать обучение можно в любой момент (Ctrl+C или закрыть окно). Чекпоинты сохраняются:
- BC — каждые 1000 шагов;
- PPO — каждые 50 обновлений.

## 8. Если что-то не так

| Проблема | Что делать |
|---|---|
| `Нет чекпоинта` | обучение ещё не дошло до первого сохранения: BC сохраняет на шаге 1000 |
| `ModuleNotFoundError: torch` | запускать через `..\.venv\Scripts\python.exe`, а не через `python` |
| окно `play.py` тормозит во время обучения | добавить `--cpu`: видеокарта занята обучением |
| `--record` не сохранил файл | без `--headless` демо сохраняется только если уровень пройден |
| `make_level.py`: «ровно один Мёрфи» | на карте должен быть один символ `M` |
| кракозябры в консоли | `$env:PYTHONIOENCODING = "utf-8"` |
