# Инструменты Supaplex: просмотр уровней и датасет для обучения

В этом репозитории два Python-инструмента и доработанная игра OpenSupaplex:

| Что | Файл | Зачем |
|---|---|---|
| Просмотр уровней | [supaplex_viewer.py](supaplex_viewer.py) | смотреть уровни из `LEVELS.DAT` / `supaplex.dat` / `.sp` с оригинальной графикой игры, сохранять PNG |
| Датасет | [supaplex_dataset.py](supaplex_dataset.py) | превращать записанные демо в покадровый датасет (наблюдение → действие) для imitation learning / RL |
| Игра | `OpenSupaplex/OpenSupaplex.exe` | играть, записывать демо; добавлены быстрое сохранение (F5/F9) и масштаб вида (Z/X) |
| Утилита датасета | `OpenSupaplex/supaplex-dataset.exe` | headless-проигрыватель демо, его вызывает `supaplex_dataset.py` |

## Установка

Нужен Python 3.10+ и две библиотеки:

```powershell
pip install pillow numpy
```

`tkinter` (окно просмотра) входит в стандартную поставку Python для Windows.

Ожидаемая структура папок (как в этом репозитории):

```
git_repo/
├── supaplex_viewer.py
├── supaplex_dataset.py
├── supaplex.dat                  # уровни (то же, что LEVELS.DAT)
└── OpenSupaplex/
    ├── OpenSupaplex.exe          # игра (доработанная)
    ├── supaplex-dataset.exe      # утилита для датасета
    ├── FIXED.DAT, MOVING.DAT, PALETTES.DAT, ...   # графика и данные игры
    └── SDL2.dll, SDL2_mixer.dll, ...
```

Все команды ниже запускаются из папки `git_repo`.

## Просмотр уровней — supaplex_viewer.py

Рисует уровни так же, как игра: тайлы из `FIXED.DAT`, рамку из `MOVING.DAT`, цвета из `PALETTES.DAT`.
Читает:

- `LEVELS.DAT`, `supaplex.dat`, `LEVELS.Dxx` — наборы уровней по 1536 байт;
- одиночный уровень или демо `.sp` / `.SP` (берётся уровень, запись нажатий игнорируется).

### Интерактивный просмотр

```powershell
python supaplex_viewer.py supaplex.dat
python supaplex_viewer.py supaplex.dat --level 34          # открыть сразу 34-й уровень
python supaplex_viewer.py OpenSupaplex\00S001-0.SP         # уровень из записанного демо
```

Окно: слева список уровней, сверху информация об уровне (сколько инфотронов нужно, гравитация,
заморозка зонков, число спец-портов), снизу строка состояния.

| Клавиша / действие | Что делает |
|---|---|
| `←` `→`, `PgUp` `PgDn` | предыдущий / следующий уровень |
| `Home` `End` | первый / последний уровень |
| `+` `-` | масштаб ×1…×4 |
| `C` | показать / скрыть числовые коды тайлов |
| `P` | подсветить спец-порты (включено по умолчанию) |
| `G` | сетка |
| `S` | сохранить текущий вид в PNG (в папку `--out`, по умолчанию `supaplex_output`) |
| колесо мыши / `Shift`+колесо | прокрутка по вертикали / горизонтали |
| наведение мыши | координаты клетки, тип тайла, настройки спец-порта |
| клик по списку | перейти к уровню |

### Экспорт в PNG

```powershell
python supaplex_viewer.py supaplex.dat --export                    # все уровни, масштаб 1 (944×368)
python supaplex_viewer.py supaplex.dat --export --scale 2 --out png2x
python supaplex_viewer.py supaplex.dat --export --schematic        # старый режим: цветные клетки с кодами
```

В папке вывода появятся:

- `001_WARM UP.png`, `002_EXIT!.png`, … — по картинке на уровень;
- `all_levels.png` — все уровни на одном листе;
- `levels.txt` — по каждому уровню: сколько инфотронов нужно, гравитация, спец-порты и сколько каких тайлов.

### Опции

| Опция | Описание |
|---|---|
| `levels_file` | файл уровней (`.dat` или `.sp`) |
| `--gfx ПАПКА` | где лежат `FIXED.DAT`, `MOVING.DAT`, `PALETTES.DAT`. По умолчанию ищется рядом с файлом уровней, в `./OpenSupaplex` и в `./superplexed-0_21_win-x64/gamedata` |
| `--level N` | с какого уровня открыть окно |
| `--export` | не открывать окно, а сохранить PNG всех уровней |
| `--schematic` | (с `--export`) цветные клетки с кодами вместо графики; графика игры не нужна |
| `--scale N` | (с `--export`) масштаб PNG 1…4 |
| `--out ПАПКА` | куда сохранять PNG (по умолчанию `supaplex_output`) |

Как игра, просмотрщик рисует внешний ряд клеток рамкой, а тайлы с кодом ≥ 40 — пустотой.

## Новые клавиши в игре

В `OpenSupaplex.exe` добавлено:

| Клавиша | Что делает |
|---|---|
| `F5` | быстрое сохранение в любой момент уровня (на панели `QS`) |
| `F9` | быстрая загрузка (на панели `QL`; `XX` — в этом уровне ещё нет сохранения) |
| `Z` | показать больше уровня (отдалить), до всего уровня целиком |
| `X` | показать меньше уровня (приблизить), до обычного вида |
| `P` → `RECORD DEMO: N` | начать запись демо (уровень начнётся заново) |

Что важно знать:

- Быстрое сохранение живёт только в памяти и стирается при входе в уровень и выходе из него.
  Загружаться можно сколько угодно раз, в том числе сразу после гибели Мёрфи, пока уровень не закрылся.
- После загрузки всё продолжается точно так же, как если бы загрузки не было: снік-снаки, электроны,
  падающие зонки и «баги» сохраняют направление, скорость и даже случайность.
- `Z`/`X` меняют только картинку в окне. На логику игры и на кадры датасета они не влияют.
- Если демо записывается, `F9` перематывает запись к моменту сохранения: в файле остаётся только путь,
  который вы в итоге оставили, без ошибок и смертей. Такой файл проигрывается без ошибок.

## Датасет — supaplex_dataset.py

### Как это работает

```
 игра (запись демо)          supaplex-dataset.exe                 supaplex_dataset.py
 ┌─────────────────┐  .SP   ┌──────────────────────────┐  .spds  ┌──────────────────┐  .npz
 │ вы играете      │ ─────▶ │ проигрывает демо движком │ ──────▶ │ упаковывает в    │ ─────▶ обучение
 │ (F5/F9 можно)   │        │ игры без окна, на каждом │         │ numpy-массивы,   │
 └─────────────────┘        │ кадре пишет наблюдение и │         │ сжимает          │
                            │ действие                 │         └──────────────────┘
                            └──────────────────────────┘
```

Демо (`.SP`) — это уровень плюс последовательность нажатий. Игра полностью детерминирована,
поэтому из демо можно восстановить каждый кадр. Утилита проигрывает демо настоящим движком,
и датасет совпадает с тем, что было в игре, бит в бит.

### Шаг 1. Записать демо

1. Запустите `OpenSupaplex\OpenSupaplex.exe` и выберите уровень.
2. Во время игры нажмите `P` (пауза) → `RECORD DEMO: 0` (номер — слот, 0…9).
3. Уровень начнётся заново, идёт запись. Играйте. `F5`/`F9` можно использовать.
4. Пройдите уровень (или выйдите — неудачные попытки тоже можно сохранять в датасет).
5. Файл появится в папке игры: `OpenSupaplex\00S<номер уровня>-<слот>.SP`, например `00S001-0.SP`.

> Следующая запись в тот же слот перезапишет файл. Чтобы не потерять демо, переименуйте или
> перенесите его, например в папку `demos\`.

Готовые демо тоже подходят: 6439 решений уровней лежат в
`D:\git_repo_src\open-supaplex\tests\solves`. Это готовые экспертные траектории.

### Шаг 2. Собрать датасет

```powershell
# одно демо
python supaplex_dataset.py build OpenSupaplex\00S001-0.SP --out dataset

# все свои демо из папки (ищутся *.sp / *.SP рекурсивно)
python supaplex_dataset.py build demos --out dataset

# только сетка уровня, без кадров экрана: в ~70 раз меньше
python supaplex_dataset.py build demos --out dataset_grid --no-screen

# все решения сообщества, 8 потоков, пропуская уже готовые файлы
python supaplex_dataset.py build D:\git_repo_src\open-supaplex\tests\solves --out dataset_solves --no-screen --jobs 8 --skip-existing
```

Для каждого демо получается один эпизод `ИМЯ.npz`. Во время сборки печатается, сколько шагов в эпизоде
и решён ли уровень.

| Опция `build` | Описание |
|---|---|
| `inputs…` | файлы демо, маски (`demos\*.SP`) или папки |
| `--out ПАПКА` | куда класть `.npz` (по умолчанию `dataset`) |
| `--no-screen` | не сохранять кадры экрана, только сетку и скаляры |
| `--game-dir ПАПКА` | папка с `supaplex-dataset.exe` и данными игры (по умолчанию `./OpenSupaplex`) |
| `--jobs N` | сколько демо обрабатывать параллельно (по умолчанию половина ядер) |
| `--skip-existing` | не пересобирать уже существующие `.npz` |

Размер: около 10 000 шагов (≈5 минут игры) — это ~40–50 МБ с кадрами экрана или ~0.6 МБ с `--no-screen`.

### Шаг 3. Проверить

```powershell
python supaplex_dataset.py info dataset\00S001-0.npz
python supaplex_dataset.py preview dataset\00S001-0.npz --out preview.gif
python supaplex_dataset.py preview dataset\00S001-0.npz --out frame.png --start 500 --max-frames 1
```

Команда `info` печатает имя уровня, решён ли он, число шагов, частоту каждого действия и формы массивов.
Команда `preview` делает GIF/PNG из кадров с подписью действия.

| Опция `preview` | Описание |
|---|---|
| `--out` | `.gif` — анимация, иначе один кадр (PNG) |
| `--start N` | с какого шага начать |
| `--every N` | брать каждый N-й кадр (по умолчанию 4) |
| `--max-frames N` | сколько кадров максимум (по умолчанию 300, 0 = все) |

### Шаг 4. Использовать в коде

```python
from supaplex_dataset import load_episode, ACTION_NAMES

ep = load_episode("dataset/00S001-0.npz")

t = 500
ep["screens"][t]      # (200, 320) uint8 — кадр в индексах палитры
ep["tiles"][t]        # (24, 60) uint8 — тип тайла в каждой клетке
ep["states"][t]       # (24, 60) uint8 — фаза движения тайла
ep["actions"][t]      # действие игрока в этом кадре, 0..9
ACTION_NAMES[ep["actions"][t]]   # 'left', 'space+up', ...

rgb = ep["palette"][ep["screens"][t]]   # (200, 320, 3) — цветная картинка
```

Наблюдение шага `t` — состояние в начале кадра `t`, то, что видит игрок перед решением.
`actions[t]` — нажатие, применённое в этом кадре. После него игра переходит в наблюдение `t+1`.

## Пример: от игры до обучающих данных

Полный сценарий: записать несколько своих прохождений, собрать из них датасет и подготовить
массивы `X, y` для обучения с учителем (behavior cloning).

**1. Запись.** Пройдите в игре уровни 1–3 с записью (`P` → `RECORD DEMO`) и перенесите файлы:

```powershell
mkdir demos
move OpenSupaplex\00S00*.SP demos\
```

**2. Сборка.**

```powershell
python supaplex_dataset.py build demos --out dataset
python supaplex_dataset.py info dataset\*.npz
```

**3. Подготовка данных** (`prepare_bc.py`):

```python
import glob
import numpy as np
from supaplex_dataset import load_episode, ACTION_NAMES

X_grid, X_screen, y = [], [], []

for path in sorted(glob.glob("dataset/*.npz")):
    ep = load_episode(path)
    if not ep["solved"]:
        continue                      # для клонирования берём только успешные прохождения

    # Мёрфи переходит на соседнюю клетку за 8 кадров: берём каждый 4-й кадр,
    # чтобы выкинуть почти одинаковые соседние шаги
    idx = np.arange(0, len(ep["actions"]), 4)

    X_grid.append(np.stack([ep["tiles"][idx], ep["states"][idx]], axis=1))  # (N, 2, 24, 60)
    X_screen.append(ep["screens"][idx])                                       # (N, 200, 320)
    y.append(ep["actions"][idx])                                              # (N,)

X_grid = np.concatenate(X_grid)
X_screen = np.concatenate(X_screen)
y = np.concatenate(y)

print("примеров:", len(y))
for a, n in enumerate(np.bincount(y, minlength=len(ACTION_NAMES))):
    print(f"  {ACTION_NAMES[a]:12s} {n}")

np.savez_compressed("bc_data.npz", grid=X_grid, screen=X_screen, action=y)
```

**4. Простая награда для RL** (если нужна): например, +1 за каждый собранный инфотрон,
+10 за прохождение и −10 за гибель:

```python
import numpy as np
from supaplex_dataset import load_episode

ep = load_episode("dataset/00S001-0.npz")
collected = -np.diff(ep["infotrons_left"].astype(np.int16), append=ep["infotrons_left"][-1])
reward = (collected.clip(min=0)
          + 10.0 * (np.diff(ep["completed"].astype(np.int8), append=0) > 0)
          - 10.0 * (np.diff(ep["failed"].astype(np.int8), append=0) > 0))
done = ep["completed"] | ep["failed"]
```

Как устроены фазы в `states`, см. в справочнике ниже. Для обучения сетку удобно подавать как
one-hot по `tiles` плюс `states` отдельным каналом. Учтите, что кроме кодов 0–39 в `tiles` во время
игры бывают служебные значения.

## Справочник

### Поля эпизода `.npz`

`T` — число шагов (игровых кадров, 35 в секунду).

| Ключ | Тип, форма | Описание |
|---|---|---|
| `actions` | `uint8 (T,)` | действие в кадре (коды ниже) |
| `tiles` | `uint8 (T, 24, 60)` | тип тайла по клеткам, `[y, x]` |
| `states` | `uint8 (T, 24, 60)` | фаза движения тайла (0 — стоит на месте) |
| `screens` | `uint8 (T, 200, 320)` | кадр экрана в индексах палитры: верхние 176 строк — вид уровня, нижние 24 — панель. **Нет при `--no-screen`** |
| `palette` | `uint8 (16, 3)` | RGB палитра для `screens` |
| `frames` | `uint32 (T,)` | номер игрового кадра |
| `infotrons_left` | `uint8 (T,)` | сколько инфотронов ещё нужно собрать |
| `red_disks` | `uint8 (T,)` | сколько красных дисков у Мёрфи |
| `murphy_xy` | `int16 (T, 2)` | клетка Мёрфи `(x, y)` |
| `failed` | `bool (T,)` | Мёрфи погиб, уровень вот-вот закроется |
| `completed` | `bool (T,)` | уровень пройден |
| `gravity` | `bool (T,)` | включена гравитация |
| `level` | `uint8 (1536,)` | сам уровень, в формате `LEVELS.DAT` |
| `level_name` | строка | имя уровня |
| `solved` | `bool` | решён ли уровень этим демо |
| `source` | строка | путь к исходному демо |

### Коды действий

| Код | Имя | Нажатие |
|---|---|---|
| 0 | `none` | ничего |
| 1 | `up` | ↑ |
| 2 | `left` | ← |
| 3 | `down` | ↓ |
| 4 | `right` | → |
| 5 | `space+up` | пробел + ↑ (съесть/толкнуть сверху, не сдвигаясь) |
| 6 | `space+left` | пробел + ← |
| 7 | `space+down` | пробел + ↓ |
| 8 | `space+right` | пробел + → |
| 9 | `space` | только пробел (положить красный диск) |

### Коды тайлов (`tiles`, уровни)

| Код | Тайл | Код | Тайл |
|---|---|---|---|
| 0 | пустота | 20 | красный диск |
| 1 | зонк | 21 | порт ↕ |
| 2 | база (зелёная плата) | 22 | порт ↔ |
| 3 | Мёрфи | 23 | порт 4-way |
| 4 | инфотрон | 24 | электрон |
| 5 | RAM-чип | 25 | баг |
| 6 | стена (hardware) | 26, 27 | RAM-чип левый/правый |
| 7 | выход | 28–37 | стены разного вида |
| 8 | оранжевый диск | 38, 39 | RAM-чип верх/низ |
| 9–12 | порт → ↓ ← ↑ | | |
| 13–16 | спец-порт → ↓ ← ↑ | | |
| 17 | снік-снак | | |
| 18 | жёлтый диск | | |
| 19 | терминал | | |

Во время игры встречаются и служебные значения (например, взрыв 31, «клетка занята движущимся
объектом» и др.): игра так помечает объекты в движении. Их лучше подавать в модель как есть.

### Формат сырого файла `.spds`

Его пишет `supaplex-dataset.exe`, а `supaplex_dataset.py` сразу превращает его в `.npz` и удаляет.
Пригодится, если читать данные из другого языка. Порядок байт — little endian.

```
"SPDS" | u16 версия=1 | u16 флаги (бит0: есть экран) | u16 320 | u16 200 | u16 60 | u16 24
u8[1536] уровень | u8[48] палитра RGB
шаги: u32 кадр | u8 действие | u8 флаги (бит0 погиб, бит1 пройден, бит2 гравитация)
      | u8 инфотронов осталось | u8 красных дисков | u16 клетка Мёрфи | u16 резерв
      | u8[24*60*2] сетка (тайл, фаза) | u8[200*320] экран (если есть)
"SEND" | u32 число шагов | u8 решён
```

Утилиту можно вызвать напрямую (из папки игры):

```powershell
cd OpenSupaplex
.\supaplex-dataset.exe ..\demos\00S001-0.SP ..\out.spds [--no-screen]
```

## Частые проблемы

**`Не найдены файлы графики (FIXED.DAT, MOVING.DAT, PALETTES.DAT)`** — укажите папку игры:
`python supaplex_viewer.py supaplex.dat --gfx OpenSupaplex`.

**`Не найден ...\supaplex-dataset.exe`** — укажите папку игры: `--game-dir путь\к\OpenSupaplex`.

**Демо не решает уровень (`НЕ решён`)** — так бывает, если запись прервали, Мёрфи погиб или
демо записано для другого набора уровней. Такие эпизоды тоже сохраняются (`solved = False`):
их можно отбросить или использовать как отрицательные примеры.

**Часы на панели в кадрах датасета показывают 00:00:00** — в игре часы идут по реальному времени,
а утилита проигрывает демо быстрее реального. На логику игры и остальные данные это не влияет.

**Кракозябры в консоли** — включите UTF-8: `$env:PYTHONIOENCODING = "utf-8"` (PowerShell)
или `chcp 65001`.

**Запись демо в обычном режиме через Ctrl+F1 не работает** — эти комбинации работают только в
